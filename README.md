# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリーはファイルや履歴を保管する場所
- ローカルリポジトリーは自分の作業空間、オフラインでも動作可能

## プッシュとマージの違いは何でしょうか？
- pushは、ローカルリポジトリーの変更操作をリモートリポジトリーに送信する操作。
- Mergeは別々に開発したブランチを統合する操作。

## コミットとプッシュの違い
- コミットはパソコン上のリポジトリーに変更を記録する。
- プッシュはGitHubなどのリモートリポジトリーに反映、共有する操作。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- ローカルリポジトリー内の変更点の記載。


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
-  ローカルマージは個人的な作業・速度を優先、プルリクエストは、チーム開発での品質・履歴管理を優先すること。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
-  どの変更点を残すか判断、ファイルを手動で修正する。
